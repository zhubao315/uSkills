# uSkills

uSkills 是以驾驭工程为方法论构建的 Agent 技能底座，用于把历史 SOP Prompt 转换为标准化、可治理、可复用的技能资产。

## 为什么是 uSkills

- 把零散 Prompt 沉淀成版本化资产
- 将 Agent 执行过程纳入可监控、可干预、可回滚的治理框架
- 通过 GitHub 原生工作流完成协作、校验、发布

## V1.0 交付内容

- SOP Prompt 批量拆分和标准化转换
- `USkill` Pydantic Schema 与 JSON Schema
- YAML/JSON 技能校验
- 技能索引自动生成
- GitHub Actions 自动测试和 Pages 发布
